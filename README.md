# Intro to Performance Analysis Dashboard

## The objective of this project was to learn Excel and Advance Excel tools to bring out best in visualisation for a extracted data.
### So Here I have used Nifty Index data and Multiple Mutual Funds Data and Derived aggregation for last 2 years of data upto April 4 2025.<br>
### I have ensured the consistency in data by following ETL Principles properly.
- [x] Extraction - Transformation - Load > post this process I obtained a clean dataset which was ready to use for the dashboard.
- [x] Now I spent time learning Visual Basic Macros which are a part of Excel to Dynamically Populate Charts based on dropdown.
- [x] This project helped me learn and develop my core foundational skills in using Macros of Excel, Advance Excel, Pivots with Slices in Excel for better visualisation. <br>

### The List of companies used are only five in this case for Performance Analysis. They have been choosen very carefully by studying the % of allocation given for companies which are common in most mutual funds

### You can download the excel and also watch the video or playaround to understand the performance of the 5 stocks which are highly allocated in Mutual fund company.
